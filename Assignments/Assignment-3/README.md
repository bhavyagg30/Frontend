# Frontend Lab Assignment 3

This repository contains five beginner-friendly HTML, CSS, and JavaScript exercises.

## Projects
1. BMI Calculator — calculates BMI and displays a category.
2. Signup Page — validates required fields, email, password length, and password confirmation.
3. Theme Changer — switches between light and dark themes.
4. Digital Clock — updates the current time every second.
5. To-Do List — add tasks, mark them completed, and delete them.

## How to run
Open any project's `index.html` file in a web browser. No installation is required.

## Files
Each project has its own `index.html`, `style.css`, and `script.js`.
